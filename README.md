## 🚀 ¿Cómo Ejecutar el Proyecto Sin Instalar Nada? (Modo Presentación)
### Pasos para correr el MVP con Live Server:
1. Abra la carpeta **`/dist`** del proyecto en **VS Code**.
2. Haga clic derecho sobre el archivo **`dist/index.html`**.
3. Seleccione la opción **"Open with Live Server"**.
4. La aplicación se abrirá en su navegador
